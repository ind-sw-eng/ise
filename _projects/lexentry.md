## Project Overview

Lexentry partnered with ISE students to create a GenAI-powered system that detects GDPR violations across internal corporate channels. It uses AI to flag potential privacy and compliance issues.

## Core Capabilities

1. **Automated Detection**: AI-powered identification of GDPR violations
2. **Real-time Monitoring**: Continuous compliance monitoring across configurable systems (Exchange mail, Slack, Google Workspace)
3. **GDPR Violation Assessment**: Detection of Article 9 GDPR violations
4. **Flexible Compliance Reporting**: Specific GDPR articles can be enabled or disabled
5. **NFRs**: Security, scalability and extensibility

 
## Technical Architecture

The system was developed using:
1. Large Language Models (LLMs) for text analysis
2. C# backend with .NET packages
3. API.NET and API SDKs
4. Inspection and detection engine written in Python with Dagster data orchestration
5. Frontend in TypeScript, Next.js, Tailwind and pnpm


## Impact

The system has significantly reduced manual compliance review time and increased accuracy in identifying potential GDPR violations, helping organizations keep their data protection standards high.
