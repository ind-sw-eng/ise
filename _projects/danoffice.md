## Project Overview

DanOffice partnered with ISE students to improve its image recognition by retraining an AI model. The project focused on the accuracy and performance of an existing computer vision system. The goal: let on-site, non-technical people retrain and publish an AI model as part of a line clearance process. 


## Key Achievements

1. **Model Improvement**: Improved image classification
2. **Process Improvement**: Non-technical people can retrain and publish an AI model in a line clearance process

## Technical Overview

The project was built using:

1. A Jupyter notebook running the AI codebase
2. Google Colab for cloud-based Python execution with GPU support on Google's GPU servers
3. Google Drive for image and file storage
4. HTML and CSS for the user interface
5. Docker for app containerization
6. Azure for cloud hosting
7. ASP.NET for the backend
8. Identity framework for user authentication
9. Entity Framework Core for database interactions
10. SQLite as the database server


## Impact

The retrained image recognition has improved DanOffice's product offering, and non-technical people can now retrain and publish AI models themselves.
