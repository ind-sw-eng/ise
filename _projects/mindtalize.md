## Project Overview

Mindtalize partnered with ISE students to develop an employee mindset survey web application. The app lets organizations gather, analyze and act on employee feedback to improve workplace culture and productivity.

## Core Features

1. **Survey Builder**: Customizable questionnaire creation tool
2. **Multi-format Questions**: Text, multiple choice, rating scales, and more
3. **Analytics Dashboard**: Visuals for both Employee Insights and Leadership Insights
4. **Anonymity Protection**: Secure anonymous response collection
5. **Editable Surveys**: Non-coders can edit existing surveys
6. **Mobile Responsive**: Optimized for mobile devices
7. **Multi-language capability**: Danish and English

## Technical Architecture

The application was built using:
1. React for the frontend interface
2. Node.js backend with Express
3. JavaScript across backend and frontend
4. Chart.js for customizable chart components
5. MariaDB as the database, hosted on Cloudways
6. Docker for an identical development environment on every team member's machine


## Impact

The ISE team achieved its goal: a working MVP of the employee mindset survey web application.
